Accessibility options

You can adjust the experience before starting the check so the text, controls, and audio guidance suit you better.

Text size

Increase the base text size so instructions and buttons stay readable.

Contrast

Use a higher contrast mode to make text and controls easier to see.

Audio guidance

Enable spoken instructions for consent, setup, and help steps.

Answer methods

  • Type the letter with your keyboard.
  • Use the large on-screen tap buttons.

Keyboard tips

  • H opens help during the test.
  • Esc pauses the test.
  • Number keys can be used for tap answers.
Tip: The most reliable result comes from stable lighting, reduced glare, and staying at the same distance from the screen.
